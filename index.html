Clean Anywhere — Video & Picture

Privacy Policy

Last updated: 18 November 2026

Clean Anywhere is a browser extension that changes how YouTube videos are displayed. It provides a distraction-free video window, zoom, pan, aspect-ratio and picture adjustments, and window positioning. This policy describes the information the extension accesses and stores.

Information the extension accesses

  • YouTube website content: The extension interacts with the YouTube video player and page elements to provide video viewing controls and hide parts of the page.
  • Video identifiers: When per-video settings are enabled, the extension reads the YouTube video identifier from the page URL and may save that identifier with the corresponding display settings. These identifiers may indicate which videos have customized settings; the extension does not build or transmit a full browsing history.
  • Display information: The extension accesses monitor geometry, display positions and usable screen areas to place and size windows. It does not capture screenshots or record the screen.
  • Interface input: Mouse movement and keyboard actions are handled as needed to display controls and operate shortcuts. The extension does not log or transmit them.

Information stored locally

The extension stores display preferences, including zoom, pan, crop, stretch/fit modes, brightness, contrast, saturation, control visibility and window placement preferences, in the browser's local extension storage. Depending on the selected settings, it may associate some preferences with individual YouTube video identifiers.

Temporary browser session storage is used to help return a video tab to its prior browser window when leaving Clean video mode.

Data transmission and sharing

The extension does not send stored preferences, video identifiers, or other user information to a server operated by the extension publisher. It does not include analytics, advertising trackers or data-selling features. The extension uses packaged JavaScript and does not load executable code from a remote server.

Video playback and YouTube website services remain operated by YouTube and are subject to their own privacy practices. The extension does not control data handled directly by YouTube or the browser.

Why this information is used

Website content and optional video identifiers are used exclusively to display and customize the user's videos. Display information is used to arrange the video window on the user's monitor. Locally stored preferences make the user's chosen viewing settings persist.

Retention and user control

Local preferences remain until they are reset or the extension's stored data is cleared. Users can reset picture settings using the extension's controls and can remove the extension or clear its data using browser extension settings. Temporary session data is managed by the browser and is not intended as permanent history.

Changes to this policy

This policy may be updated when Clean Anywhere's features or data handling practices change. The latest revision date will be displayed at the top of this page.
